# 公网部署指南

比赛的 Web 作品需要公网可访问链接。本项目可以部署到任意支持 Docker 和 HTTPS 的平台，例如 Sealos、Cloudflare 容器服务、Railway 或 Render。

当前已部署的匿名 Demo：<https://pnnsklzkknse.sealoshzh.site>。部署验收证据见 [公网部署验收记录-20260911.md](公网部署验收记录-20260911.md)。

## 平台配置

- 构建方式：使用项目根目录 `Dockerfile`；
- 服务端口：`8765`；
- 健康检查：`/api/health`；
- 必填 Secret：`ZHIHU_ACCESS_SECRET`；
- 可选环境变量：`ZHIHU_ANSWER_MODEL=zhida-fast-1p5`；
- 推荐保留默认日软限额；需要调整时设置 `ZHIHU_DAILY_LIMIT_DIRECT_ANSWER` 等变量；
- 持久化目录：`/data`，建议挂载数据卷。

不要把真实 Access Secret 写入 Dockerfile、`.env`、GitHub Actions 日志或截图。

## 本机先验收容器

```bash
docker build -t zhihu-knowledge-alchemist .
docker run --rm -p 8765:8765 -e ZHIHU_ACCESS_SECRET="你的值" zhihu-knowledge-alchemist
```

打开 `http://127.0.0.1:8765`，先测试匿名 Demo，再测试一个真实问题。公网部署成功后访问：

```text
https://你的域名/api/health
```

确认 `ok` 为 true，页面显示“官方接口已连接”。

## 正式提交前检查

- 使用无痕窗口打开公网链接；
- 不登录 Codex 也能完成核心体验；
- Access Secret 不出现在页面源代码或网络请求体；
- 重复同一问题时页面显示缓存命中；
- Markdown 能正常下载；
- 手机宽度下输入、按钮和来源列表不溢出；
- 准备一段备用视频，防止现场网络或配额异常。

## OAuth 说明

本项目已确认接入知乎账号登录。必须先获得公网 HTTPS 域名，再把回调地址配置为 `https://你的域名/auth/callback`，并在知乎应用后台登记完全相同的地址。本地地址只能预览页面，不能完成真实登录；匿名 Demo 仍保留用于评委无需登录的核心体验。
