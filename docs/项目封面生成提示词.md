# 项目封面生成提示词

## 用途

知乎黑客松项目广场 16:9 封面，推荐输出 1920 x 1080 PNG。

## 提示词

```text
一张原创的现代知识工具项目封面。深冷灰背景，大量分散的讨论碎片和纸张卡片从四周汇聚到中央偏右位置，最终形成四层清晰、有秩序的半透明知识结构，分别暗示观点对照、知识简报、学习卡片和行动路线。细线把结构化成果连接回原始碎片，表达可追溯性。精致克制的 3D 编辑插画，真实纸张与磨砂亚克力质感，冷静、可信、适合学生知识产品。配色只使用炭灰、银灰和一种克制的蓝色。16:9 横版，在缩略图尺寸下仍有明确主体。

不要文字、字母、数字、人物、Logo、商标、水印、伪界面、紫色渐变、霓虹赛博朋克、外发光或拥挤装饰。
```

## 人工检查

- 画面中没有不可读的伪文字；
- 没有知乎 Logo 或第三方标识；
- 只有一种蓝色强调色；
- 缩小到手机宽度仍能看清“碎片汇聚成结构”；
- 需要加项目名称时，在投稿平台的标题字段添加，不把标题烧进图片。
