# 跨账号与换机指南

这个项目可以在其他电脑、其他 Codex 账号和其他知乎账号上运行。压缩包中只包含程序、Skill、演示数据和文档，不包含任何账号凭证。

## 新电脑上的安装步骤

1. 把项目压缩包复制到新电脑并解压。
2. Windows 运行 `install-windows.ps1`；macOS 运行 `install-mac.command`。
3. 重启 Codex，确认 12 个知识炼金 Skill 与 2 个官方 Skill 已出现。
4. 先用“载入演示”验证无密钥流程。
5. 需要实时数据时，用该电脑上实际使用的知乎账号配置它自己的 Access Secret。

Skill 会安装到当前操作系统账号的 `.codex/skills/`，因此同一台电脑的不同系统账号也需分别安装。

## 账号与数据隔离

- Codex 账号：只负责运行 Skill，不会被写进项目。
- 知乎账号：每个账号使用它自己的 Access Secret；需要登录能力时，还需要该应用的 App ID 和 App Key。
- 本地数据：默认保存在当前系统账号的 `.zhihu-knowledge/projects.db`，不会自动同步到其他电脑。
- 公网部署：密钥只放在部署平台 Secret/环境变量中，不进入压缩包、镜像或 Git 仓库。

## 使用私有 GitHub 仓库

如果代码仓库和 GHCR 镜像保持私有，其他 GitHub 账号默认无权访问。可选方式：

- 直接使用压缩包，不需要 GitHub 权限；
- 把新 GitHub 账号添加为私有仓库协作者；
- 在新账号下建立独立私有仓库和镜像。

部署平台拉取私有 GHCR 镜像时，使用专用的只读凭证，只授予 `read:packages`，不要传入日常 GitHub 登录凭证。凭证过期后需在部署平台更换。

## OAuth 换账号

OAuth 应用属于申请它的开发者账号。换用另一个知乎开发者账号时，需要重新获取 App ID、App Key 和 Access Secret，并把同一个公网 HTTPS 回调地址登记到新应用。普通用户授权登录不需要安装 Skill，只需访问已部署的网页。
