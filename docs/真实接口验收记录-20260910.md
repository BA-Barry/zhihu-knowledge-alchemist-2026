- 用户已明确选择接入知乎账号登录；

- 取得公网 HTTPS 地址后，回调统一使用 `https://<公网域名>/auth/callback`；
- 未取得 App ID、App Key 和公网回调前，不宣称真实 OAuth 已打通。

## 安全备注

Access Secret 曾被用户直接粘贴到对话中。正式演示或部署前应在开放平台轮换，并把新值仅配置到系统凭证库或部署平台 Secret，避免再次通过聊天、命令参数、源码、截图或 Git 传递。
