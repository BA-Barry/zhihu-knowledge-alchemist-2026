## 产品名称

知乎技术知识炼金助手

## 一句话介绍

把知乎多元回答转化为有来源边界的观点矩阵、知识简报、学习卡片和可验证行动路线。

## 200-500 字介绍

直接使用并按真实联调结果修订 `docs/200-500字项目介绍.md`。

## 核心实现

- 知乎官方搜索召回真实讨论并保留社区语境；
- 知乎直答在本次来源范围内生成结构化成果；
- SQLite 保存项目、来源、成果与配额缓存；
- 网页提供输入、加载、错误、结果、来源核查和 Markdown 导出；
- 12 个 Codex Skill 支持完整知识研究流程；
- Docker 支持公网部署，密钥仅放在服务端 Secret。
