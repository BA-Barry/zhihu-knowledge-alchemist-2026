# 比赛适配说明

## 赛道判断

项目与“知识炼金场：学习工具与知识生产”高度匹配。它解决的不是“再做一个摘要器”，而是知乎多回答场景中的结构化理解问题：读者难以快速识别共识、分歧、适用条件和下一步行动。

## 知乎与 AI 各自做什么

知乎提供真实问题、多元回答、作者信息、赞同与评论等社区语境，并通过官方搜索把相关内容召回。AI 负责跨来源对齐概念、保留冲突、生成知识简报和学习卡片，并把证据缺口转成可验证行动。来源编号让用户能回看原文，不把模型总结当成社区原话。

去掉知乎，产品失去多观点社区知识；去掉 AI，用户仍要逐条阅读和手工整理。两者都位于核心流程。

## 对应评分项

- AI 场景价值：一次点击把多回答阅读变成理解、复习与行动；
- 创新性：保留分歧和证据边界，不按最高赞替用户决定；
- 完成度：匿名演示、官方实时模式、缓存、导出、测试和 Docker 部署均已实现；
- 使用体验：评委无需进入 Codex 即可在网页完成核心流程；
- 方案与演示：已准备产品方案、投稿文案和 3 分钟脚本。

## 仍需赛前完成

- 已用参赛 Access Secret 完成官方 CLI 真实联调；录制或截图时只展示脱敏状态与成功结果；
- 部署公网 HTTPS 体验链接；
- 已确认接入知乎账号登录；待配置 App ID、App Key、Access Secret 与公网 HTTPS 回调；
- 确认预开发原型是否符合 48 小时开发阶段规则；
- 填写团队资格信息并在截止时间前提交；
- 如争取开源加分，将代码仓库设为公开。
