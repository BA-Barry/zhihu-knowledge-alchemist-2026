# 产品方案书

## 产品名称

知乎技术知识炼金助手

## 参赛赛道

知识炼金场：学习工具与知识生产。

## 用户问题

知乎一个问题下常有多种经验、立场和技术路线。用户可以收藏很多回答，却很难在短时间内区分共识、冲突、适用条件与证据缺口，更难把阅读转化为可复习的知识和可执行的下一步。

## 产品方案

用户输入一个问题，系统通过知乎官方搜索召回相关公开内容并保留作者、链接、赞同和评论等语境。知乎直答只依据本次来源生成四类成果：

1. 观点与分歧矩阵：展示共识、冲突和每个来源的贡献；
2. 知识简报：给出核心概览、关键要点与未知边界；
3. 学习卡片：把结论改写成带来源编号的自测材料；
4. 创新路线：把未解决问题转成下一步验证任务和指标。

用户可以回看原始来源，也可以导出 Markdown 继续学习或创作。完整 Codex Skill 流程还支持概念图、全网证据、知识图谱和证据复核。

## 知乎与 AI 的分工

知乎完成内容召回和社区语境提供，是多观点知识的来源层。AI 完成跨回答概念对齐、冲突保留、结构化表达和行动建议，是知识转化层。AI 不把赞同数当作真伪判断，不把多个作者的内容拼成任何人的原话。

## 技术实现

产品采用 Python 标准库 Web 服务和原生 HTML/CSS/JS，数据存入 SQLite。服务端接入官方搜索、全网搜索、热榜与直答接口，请求携带 Access Secret 和时间戳。相同请求使用本地缓存以保护比赛配额。Access Secret 不进入浏览器、数据库或导出文件。Dockerfile 支持部署为公网 HTTPS 应用。

## 当前成果

已形成可运行 Web 应用、匿名备用 Demo、官方实时接口层、四类一键成果、12 个 Codex Skills、原样官方 Skill、缓存、导出、跨账号安装脚本和自动测试。匿名流程已通过测试；参赛 Access Secret 已通过官方 CLI 的凭证校验、本人内容最小读取与知乎搜索联调。正式提交前还需完成 OAuth 应用申请、官方模板迁移、公网部署与真实授权验收。

## 评估方式

- 完成一次问题输入到四类成果展示；
- 抽查学习卡片的来源编号能否回到本次搜索内容；
- 重复同一问题，验证缓存命中且不重复消耗配额；
- 让测试用户比较“逐条阅读”与“先看矩阵和卡片”两种方式的理解时间和遗漏情况。
